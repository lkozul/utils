# utils

A collection of miscellaneous utilities for use in the lab, organized by area of application.

##  Metabolomics

This section contans the following:

**Isotopologue Generator**

R script and Excel template that automatically generate all 13C- and 15N-labeled isotopologues from molecular formulas (no combined 13C+15N-labeled isotopologues)
- INPUT: Transition list for Skyline 
- OUTPUT: `.xlsx` file with individual sheets for cold, 13C- and 15N-labeled isotopologues, as well as a sheet that combines the 3 for combined tracing experiments
